## Summary
- Google OAuth was failing on Fly with `(invalid_grant) Missing code verifier.` because `Flow.authorization_url()` generates a PKCE `code_verifier`, but the callback constructed a new `Flow` without restoring it before `fetch_token`.
- `build_authorization_url` now returns `(url, code_verifier)`; start persists it via `put_oauth_state`; callback passes it into `exchange_code_for_tokens`.
- Same PKCE contract applied to incremental Google permission grants.
- Migration adds nullable `oauth_states.code_verifier` (deleted on consume).
- **Microsoft**: MSAL confidential client — no Flow PKCE; left unchanged.

## Apply on Konta Supabase (SQL editor)
