# Security Policy — Quantro Flow

## Reporting

Please **do not** open a public issue for security vulnerabilities.

Report privately to **security@quantroos.com** (or **privacidad@quantroos.com**) or via GitHub Security Advisories if available.

Include impact, reproduction steps, and contact details. We aim to acknowledge within 3 business days.

## Scope

This repository is **Quantro Flow** (public). The Quantro Information Security Program source of truth (policies, control register, vulnerability procedure) lives in the Quantro OS repository **`josh0797/konta`** under `docs/security/`.

See also: `docs/security/README.md` in this repo for a slim pointer and shared-control notes.

## Safe harbor

Good-faith research that avoids data destruction, privacy abuse, and service disruption is welcome. Do not exploit beyond demonstration; coordinate disclosure.
